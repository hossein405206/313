# سایت حلقه شهید هادی ذوالفقاری

نسخه‌ی اول سایت — صفحه‌ی خانه، فعالیت‌ها و ثبت‌نام اردو آماده‌اند.
بقیه‌ی صفحات (برنامه‌ی هفتگی، مسئولین، پیشنهاد و انتقاد، ارتباط با ما)
فعلاً به‌صورت «به‌زودی» هستند تا در قدم‌های بعد تکمیل شوند.

## ساختار فایل‌ها

```
index.html         صفحه‌ی خانه (کاروسل رویدادها + منوی ۶ تایی)
activities.html     فهرست فعالیت‌ها
register.html       فرم ثبت‌نام اردو
schedule.html       برنامه‌ی هفتگی (به‌زودی)
officials.html      مسئولین (به‌زودی)
feedback.html       پیشنهاد و انتقاد (به‌زودی)
contact.html        ارتباط با ما (به‌زودی)
css/style.css       استایل مشترک همه‌ی صفحات
js/main.js          کاروسل، ورود مربیان، منوی پایین
```

## گرفتن این نسخه روی GitHub

هیچ ابزار build‌ای لازم نیست — همین فایل‌ها به‌صورت مستقیم روی
GitHub Pages اجرا می‌شوند:

1. یک ریپازیتوری بساز و همه‌ی این فایل‌ها را در آن قرار بده.
2. در تنظیمات ریپازیتوری، بخش Pages را باز کن و شاخه‌ی اصلی
   (main) را به‌عنوان منبع انتخاب کن.
3. آدرس سایت به شکل `username.github.io/repo-name` در دسترس
   قرار می‌گیرد.

## وصل کردن به Google Sheets (قدم بعدی)

فعلاً لیست مربی‌ها و رویدادها به‌صورت آرایه‌های ثابت داخل
`js/main.js` نوشته شده‌اند (`MENTOR_NUMBERS` و `SAMPLE_EVENTS`)
تا بشود بدون بک‌اند هم سایت را تست کرد. برای وصل‌کردن واقعی به
Google Sheets:

1. یک Google Sheet بساز با شیت‌های زیر:
   - `مربیان` (ستون: شماره تلفن)
   - `رویدادها` (ستون‌ها: عنوان، تاریخ، برچسب)
   - `ثبت‌نام‌ها` (ستون‌ها: نام، نام‌خانوادگی، نام‌پدر، تلفن، وضعیت)
2. از منوی Extensions در گوگل‌شیت، Apps Script را باز کن و یک
   Web App بنویس که با متد `doGet` لیست مربیان/رویدادها را
   برمی‌گرداند و با متد `doPost` ردیف جدید به شیت «ثبت‌نام‌ها»
   اضافه می‌کند.
3. لینک Web App را در `register.html` داخل متغیر
   `GOOGLE_SCRIPT_URL` و در `js/main.js` به‌جای آرایه‌های ثابت
   قرار بده (با یک `fetch` ساده).

با این روش هیچ هزینه‌ای برای هاست یا پیامک پرداخت نمی‌شود.

## منطق فعلیِ ورود و ثبت‌نام

- **ورود مربیان:** فقط با وارد کردن شماره همراه انجام می‌شود؛
  شماره با فهرست از پیش ثبت‌شده در گوگل‌شیت مقایسه می‌شود.
- **ثبت‌نام اردو:** فرد نام، نام‌خانوادگی، نام پدر، شماره همراه
  و عکس را وارد می‌کند. رکورد با وضعیت «در انتظار تایید» ذخیره
  می‌شود و مربیان از پنل خودشان آن را تایید یا رد می‌کنند —
  بدون نیاز به کد یک‌بارمصرف پیامکی.

## قدم‌های بعدی (هنوز ساخته نشده)

- پنل مسئول حضور غیاب: ثبت روزانه‌ی حضور / موجه / غیبت برای هر نفر
- پنل مسئول نظارت: فهرست مسئولیت‌های مسجد و ثبت اخطار برای هرکس
- پنل تایید ثبت‌نام‌های اردو برای مربیان
- صفحات برنامه‌ی هفتگی، مسئولین، پیشنهاد و انتقاد، ارتباط با ما
