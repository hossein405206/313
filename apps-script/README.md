# Backend سایت 313 — نسخه 5.5.0

فایل `apps-script/Code.gs` بک‌اند Google Apps Script پروژه است.

## راه‌اندازی

### 1) Google Sheet
یک Google Sheet بساز و ID آن را بردار.

### 2) Google Drive
یک پوشه برای تصاویر رویدادها و فایل‌های ثبت‌نام بساز و ID پوشه را بردار.

### 3) Apps Script
داخل همان Google Sheet برو:

**Extensions → Apps Script**

محتوای `apps-script/Code.gs` را در فایل اصلی قرار بده و این دو مقدار را تنظیم کن:

```js
SPREADSHEET_ID: 'ID_SHEET',
DRIVE_FOLDER_ID: 'ID_FOLDER'
```

### 4) راه‌اندازی اولیه
تابع `setup()` را یک بار اجرا کن. حساب سازنده با نام و شماره تنظیم‌شده در `Code.gs` ساخته یا به‌روزرسانی می‌شود. اگر رمز هنوز تنظیم نشده باشد، پنجره‌ای برای تعیین رمز باز می‌شود. رمز خام در کد یا شیت ذخیره نمی‌شود؛ فقط هش نمک‌دار آن ثبت می‌شود. برای تعیین یا تغییر رمز مالک در هر زمان، تابع `setOwnerPassword()` را از محیط متصل به Google Sheet اجرا کن و رمز را در دو پنجره وارد کن. رمز را داخل فایل کد ننویس.

این شیت‌ها ساخته می‌شوند:

- تنظیمات
- مربیان
- مسئولین
- اعضا
- رویدادها
- اردوها
- ثبت‌نام‌ها
- حضورغیاب
- اخطارها
- بازی
- درخواست عضویت در حلقه: `درخواست عضویت`

کدهای اولیه مسئولین را حتماً بعد از setup تغییر بده.

### 5) Deploy
نسخه هماهنگ فعلی: `5.5.0`.

برای حفظ URL فعلی، از **Deploy → Manage deployments → Edit → New version → Deploy** استفاده کن. فقط اگر قصد تغییر URL داری، از **New deployment → Web app** استفاده کن.

تنظیمات:

- Execute as: **Me**
- Who has access: **Anyone**

آدرس `/exec` را بردار.

### 6) اتصال سایت
اگر URL جدید با URL داخل `js/main.js` فرق دارد، مقدار `CONFIG.API_URL` را با URL جدید عوض کن.

## منطق دسترسی

### مربی
- مدیریت رویدادها و تصاویر Drive
- مشاهده ثبت‌نام‌ها
- تایید / رد ثبت‌نام
- مشاهده گزارش حضور و غیاب ماه جاری
- مشاهده اخطارهای ماه جاری
- تعیین جایزه بازی

### مسئول حضور و غیاب
- افزودن عضو
- حذف عضو از فهرست فعال
- ثبت فقط یک‌بار در روز
- سه وضعیت: حاضر / موجه / غیبت
- اطلاعات روزهای قبلی در Sheet باقی می‌ماند اما از پنل مسئول نمایش داده نمی‌شود

### مسئول نظارت
- ثبت مسئولیت
- انتخاب نام فرد
- ثبت دلیل اخطار
- مشاهده سوابق ماه جاری

### بازی
- رکوردها بر اساس هفته ذخیره می‌شوند
- هفته از جمعه شروع می‌شود
- بهترین رکورد هفته در جدول عمومی نمایش داده می‌شود
- مربی متن جایزه را تعیین می‌کند
- مقدار پیش‌فرض:
  **به بیشترین رکورد هفته جایزه داده می شود**

## حساب و رمز عبور

- اولین ورود هر حساب با نام، شماره همراه و رمز عبور حداقل ۸ نویسه انجام می‌شود؛ دفعات بعد همان رمز برای ورود لازم است.
- حساب سازنده از قبل با نام «سیدحسین موسوی» و شماره تنظیم‌شده در `CFG.MASTER_COACH_PHONE` ساخته می‌شود.
- رمزها به‌صورت هش و نمک‌دار ذخیره می‌شوند؛ رمز خام در شیت یا کد ذخیره نمی‌شود.
- اگر رمز مالک قبلاً تنظیم شده باشد، اجرای `setup()` آن را بازنویسی نمی‌کند؛ برای تغییرش `setOwnerPassword()` را اجرا کن.
- حساب مالک با نام و شماره از پیش ثبت می‌شود. اگر رمز هنوز تنظیم نشده باشد، `setup()` آن را با دو پنجره می‌گیرد؛ برای تنظیم مجدد، تابع `resetOwnerAccountPassword()` را اجرا کن. رمز خام در مخزن عمومی قرار نمی‌گیرد.
- ورود پنل مالک نیز با همان شماره همراه و رمز حساب مالک انجام می‌شود؛ رمز در فایل عمومی نگه‌داری نمی‌شود.
- شماره همراه مسئول را در پنل مدیریت مسئولین ثبت کن تا نشان فیروزه‌ای در پروفایلش نمایش داده شود.

## عضویت در حلقه

- درخواست‌ها در شیت `درخواست عضویت` ذخیره می‌شوند.
- مالک اصلی درخواست‌ها را در پنل مربیان بررسی می‌کند.
- بازی پرنده و بازی مار فقط برای اعضای فعال و تأییدشده حلقه باز هستند.
- پس از جایگزینی `Code.gs`، تابع `setup()` را یک بار اجرا کن تا شیت جدید ساخته شود.


## نشان نقش در پروفایل

- کاربر غیرعضو: بدون حلقه دور آواتار و بدون برچسب نقش.
- عضو حلقه: آبی و برچسب «عضو حلقه».
- مسئول: فیروزه‌ای و برچسب «مسئول»؛ شماره همراه او باید در رکورد مسئول ثبت شده باشد.
- مربی: طلایی و برچسب «مربی».
- سازنده: مشکی و برچسب «سازنده».
